# Module 1 Challenge: JavaScript Basics

A simple web-based assignment demonstrating foundational JavaScript concepts, including object creation, appropriate data types, functions with arguments, string manipulation, dynamic date operations, and clean code documentation.

##Challenge Requirements Met

1. JavaScript Object: Created a structured `myInfo` object storing personal details.
2. Comprehensive Profile: Included specific properties: Name, Date of Birth, Nationality, Current Location, and Hobbies.
3. Appropriate Data Types: Employed optimal data structures (e.g., using a collection `Array` for multiple hobbies instead of a flat string).
4. Dynamic Age Calculator: Implemented an isolated function that accepts a `birthYear` argument and calculates approximate age dynamically based on the system's current calendar year.
5. Code Comments: Thoroughly documented critical processing lines for readability.
6. Version Control: Hosted and tracked on GitHub.
